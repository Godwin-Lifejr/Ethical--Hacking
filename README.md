# Ethical Hacking — Learning Notes & Labs

A collection of study notes and practical exercises documenting my learning in ethical hacking, vulnerability assessment, network reconnaissance, and security testing.

## Purpose

This repository supports my development as a cybersecurity learner. It is a place to record concepts, commands, lab observations, troubleshooting notes, and lessons learned—not a claim of professional penetration-testing experience.

## Learning Approach

- Understand the security concept before using a tool.
- Practise in intentionally vulnerable virtual machines, CTFs, or systems where I have explicit permission.
- Record the lab scope, environment, steps, observations, and limitations.
- Review results and consider defensive detection and mitigation.

## Suggested Lab Documentation

For each substantial exercise, include:

1. **Objective and scope**
2. **Lab environment and prerequisites**
3. **Tools and commands**
4. **Observed output and interpretation**
5. **Defensive lessons and remediation**
6. **Cleanup and references**

## Responsible Use

Only test systems you own or have explicit authorisation to assess. Do not use these notes to access, disrupt, or collect data from third-party systems without permission. Keep credentials, tokens, personal data, and other secrets out of commits.
